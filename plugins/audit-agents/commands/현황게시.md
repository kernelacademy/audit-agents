---
description: 감사 현황을 claude.ai 비공개 아티팩트로 올려 다른 기기에서도 본다. 다시 돌리면 같은 주소가 갱신된다
---

1. 올라가는 내용을 먼저 말한다: 회사 이름, 요청자료 받음 · 빠짐 수, 남은 일, 작업 로그(지시 앞 120자 포함), 토큰. claude.ai 에 비공개로 올라간다. 회사 이름에 「(가상)」 이 붙은 실습 회사만 있으면 묻지 않고 진행한다. 실제 고객 건이 있으면 사무소 규정상 올려도 되는지 확인받은 뒤에 진행한다.
2. `python "${CLAUDE_PLUGIN_ROOT}/bin/hub.py" status --publish` 를 돌린다. 감사 루트를 못 찾으면 `--root` 로 넣는다. 출력의 「게시용 파일」 경로와 「게시 주소」 를 읽는다.
3. 게시용 파일을 읽어 본 뒤 Artifact 도구로 그대로 게시한다.
   - `file_path` 에 게시용 파일 경로를 넣는다. 페이지를 새로 쓰거나 고치지 않는다.
   - 대시보드 타입(`type_url`)이나 quickstart 로 시작하지 않는다. 이미 만들어진 페이지를 올리는 일이다.
   - 「게시 주소」 가 있으면 `url` 에 넣어 같은 주소를 갱신한다. 「없음」 이면 새로 게시하고 `icon` 은 "checklist" 로 한다.
4. 새로 게시했으면 `python "${CLAUDE_PLUGIN_ROOT}/bin/hub.py" status --set-url "<받은 주소>"` 로 주소를 적어 둔다.
5. 주소를 한 줄로 알린다. 비공개라서 같은 계정으로 로그인해야 열리고, 다른 사람에게 보이려면 페이지의 공유 메뉴에서 초대해야 한다고 말한다.

작업 로그의 PC 경로는 게시용 파일에서 지워져 있다. 받은자료 파일 내용은 올라가지 않는다.
