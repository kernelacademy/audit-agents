---
description: AI감사팀 화면(고객사 · 인차지 · 세션 · 질문과 답변)을 claude.ai 비공개 아티팩트로 올린다. 넣은 내용은 아티팩트 저장 기능에 남고, 다시 돌리면 같은 주소를 갱신한다
---

1. 먼저 말한다: claude.ai 에 비공개로 올라가고 저장 기능(db)을 쓴다. 올리는 파일에는 회사 자료가 없다. 고객사 이름 · 연결 폴더 · 세션 상태는 화면에서 넣거나 동기화할 때만 저장된다.
2. `python "${CLAUDE_PLUGIN_ROOT}/bin/hub.py" team --publish` 를 돌린다. 감사 루트를 못 찾으면 `--root` 로 넣는다. 출력의 「게시용 파일」 경로와 「게시 주소」 를 읽는다.
3. 게시용 파일을 읽어 본 뒤 Artifact 도구로 그대로 게시한다.
   - `file_path` 에 게시용 파일 경로를 넣는다. 페이지를 고치거나 새로 쓰지 않는다. 대시보드 타입(`type_url`)이나 quickstart 로 시작하지 않는다.
   - `capabilities` 는 `{"db": {}}` 로 한다.
   - 「게시 주소」 가 있으면 `url` 에 넣어 같은 주소를 갱신한다. 저장된 고객사 · 인차지 · 세션은 그대로 남는다. 「없음」 이면 새로 게시하고 `icon` 은 "people" 로 한다.
4. 새로 게시했으면 `python "${CLAUDE_PLUGIN_ROOT}/bin/hub.py" team --set-url "<받은 주소>"` 로 주소를 적어 둔다. 이어서 ArtifactData 로 그 주소의 `settings/hub` 문서를 읽고, 없으면 `set` 으로 `{"url": "<받은 주소>"}`, 있으면 `update` 로 같은 값을 넣는다. 화면의 동기화 문장에 이 주소가 들어간다.
5. 주소를 한 줄로 알리고 사용자가 할 일을 말한다. 화면의 「설정」에서 고객사(이름 · 인차지 · 연결 폴더)와 인차지 설계 카드를 넣는다. 세션은 화면의 「동기화」 문장을 회사 폴더에서 연 세션에 보내야 올라온다. 비공개라 같은 계정으로 로그인해야 열린다.
