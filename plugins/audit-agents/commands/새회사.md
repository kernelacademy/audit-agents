---
description: 감사 루트 아래 회사 감사 폴더를 만든다. 표준 폴더, 권한 파일, 회사 CLAUDE.md, 진행메모. 같은 회사로 다시 돌리면 권한 파일만 새로 쓴다
---

인자(`$ARGUMENTS`)에서 회사 이름과 결산일(YYYY-MM-DD)을 읽는다. 빠진 것만 묻는다.

1. `python "${CLAUDE_PLUGIN_ROOT}/bin/hub.py" newcase --company "<회사>" --fy-end <결산일>` 를 돌린다. 감사 루트를 못 찾는다고 하면 `--root` 로 감사 루트를 넣어 다시 돌린다.
2. 만든 파일을 표로 보인다.
3. 「Claude 앱 Code 탭에서 `<회사 폴더>` 로 새 세션을 여세요. 처음 열 때 폴더 신뢰를 승인합니다. 받은자료는 `00 받은자료` 아래 폴더(회사제시 · 분개장 · 전기 등)에 넣습니다」 라고 안내한다. 경로는 그대로 복사할 수 있게 코드 블록에 넣는다.
