---
description: 감사 루트를 만들거나 고치고 설치를 점검한다. 감사 루트를 옮긴 뒤 다시 돌리면 회사마다 권한 파일 경로를 고친다
---

1. 인자(`$ARGUMENTS`)에 폴더가 있으면 그 폴더를 감사 루트로 쓴다. 없으면 지금 폴더 위쪽의 감사 루트를, 그것도 없으면 사용자 폴더 아래 `감사` 를 쓴다.
2. `python "${CLAUDE_PLUGIN_ROOT}/bin/hub.py" setup --root "<감사 루트>"` 를 돌려 결과를 표로 옮긴다.
3. accountingwiki MCP 의 검색 도구(search)로 「수익인식」 을 한 번 찾아 본다. 결과가 오면 통과다. 도구가 없거나 인증 오류가 나면 실패로 적고 「/mcp 에서 accountingwiki 를 골라 로그인해 주십시오」 라고 적는다.
4. 이 세션이 회사 폴더에서 열렸으면 Write 도구로 `00 받은자료/_권한시험.txt` 를 만들어 본다. 거부되면 통과다. 만들어졌으면 실패로 적고 그 파일을 지운다.
5. 끝에 통과 수 / 전체 수를 적고, 다음 할 일을 한 줄로 안내한다: 「`_맥락/조서가이드` 와 `_맥락/전기조서` 에 자료를 넣고 /audit-agents:새회사 로 첫 회사를 만듭니다」.
