# WTB 정산표

정산표의 숫자는 매번 같아야 한다. 그래서 읽기 · 계정 맞춤 · 합계 · 검산은 `scripts/wtb.py` 가 하고, 에이전트는 엑셀 셀에 숫자를 직접 쓰지 않는다. 에이전트가 하는 일은 입력 파일 고르기, 확인할 계정 판단 묻기, 수정분개 후보를 `수정.csv` 에 적기다.

## 실행

회사 폴더에서(경로는 그 회사 받은자료에 맞춘다):

```bash
python "<스킬 폴더>/scripts/wtb.py" \
  --시산표 "00 받은자료/회사제시/1.시산표_회사제시.xlsx" \
  --전기 "00 받은자료/전기/전기조서_WTB.xlsx" \
  --계정 "00 받은자료/기타/계정과목표.xlsx" \
  --분개장 "00 받은자료/분개장/2.분개장_회사제시.xlsx" \
  [--수정 "_작업/수정.csv"] --회사 "<회사>" --결산일 2025-12-31 --출력 "8100B"
```

- 필수는 `--시산표` · `--출력` 둘이다. 전기 정산표가 없으면 `--계정` 으로 코드를 맞추고 표시과목은 계정 이름으로 둔다(확인 칸에 적힌다).
- 엑셀이 있으면 한 번 계산시켜 스크립트 값과 대조한다. 엑셀이 없으면 「재계산 못 함」 으로 끝나고 스크립트 검산은 그대로 유효하다.
- 마지막 줄이 `시산표 읽기 PASS  차대 검산 PASS  엑셀 대조 PASS` 면 된다. 종료 코드 0 이 아니면 결과를 쓰지 않는다.

## 나오는 것

`<출력>/WTB_<회사>_<결산일>.xlsx` 와 `검증_WTB_<회사>_<결산일>.json`.

| 시트 | 내용 |
|---|---|
| 검산 | 검산 다섯(분개장을 주면 여섯)과 엑셀 수식 값 · 스크립트 값 · 판정, 값 지문 |
| TB | 계정코드 · 계정과목 · 표시과목 · 구분 · 회사제시 · 수정 차변 · 대변 · 최종 · 전기 최종 · 증감 · 확인 |
| AJE | 수정분개. 노란 칸에 더 적으면 TB 가 계정코드로 가져간다 |
| 재무상태표 · 손익계산서 | 표시과목별 회사제시 · 최종 · 전기 · 증감 · 증감률 |
| 분개장 대사 | 계정마다 기초 + 분개장 차변 - 대변 과 시산표 회사제시의 차이 |

## 에이전트가 할 일

1. 받은자료에서 시산표 · 전기 정산표 · 계정과목표 · 분개장을 찾아 위 명령을 돌린다. 판이 여럿이면 회계사에게 어느 판인지 묻는다.
2. 터미널 끝 줄과 `검증_*.json` 만 읽는다. 엑셀을 열어 다시 계산하지 않는다.
3. `확인할 계정` 을 회계사에게 보여 준다. 「새 계정」 은 표시과목을, 「전기에만 잔액」 은 재분류가 빠졌는지를 묻는다.
4. `분개장 대사` 차이는 원인 후보를 적는다. 전기 수정분개가 회사 장부에 안 들어갔는지, 분개장이 빠졌는지, 시산표와 분개장이 다른 판인지. 판단은 회계사가 한다.
5. 수정분개 후보는 `수정.csv`(계정코드 · 차변 · 대변 · 내역 · 근거, 한 줄에 계정 하나)에 적고 `--수정` 으로 다시 돌린다. 반영 여부는 회계사가 정한다.
6. 같은 입력으로 다시 돌렸는데 값 지문이 다르면 입력 파일이 바뀐 것이다. 무엇이 바뀌었는지 먼저 찾는다.

## 하지 않는 것

- 엑셀 셀의 숫자를 손으로 고치지 않는다. 틀리면 입력이나 `수정.csv` 를 고쳐 다시 돌린다.
- 표시과목 · 구분을 추측해 바꾸지 않는다. 전기 정산표에 없는 계정은 회계사에게 묻는다.
- 수정분개 반영 여부, 중요성 판단은 하지 않는다.

## 계정 맞춤 규칙

- 시산표의 계정 이름(공백 · 점 제거)을 전기 정산표, 다음에 계정과목표에서 찾는다. 「[10300]제예금」 처럼 코드가 붙어 있으면 코드를 쓴다.
- 이름이 같은 계정이 여럿이면(감가상각누계액) 시산표에서 바로 앞 계정보다 큰 코드 가운데 가장 작은 것을 쓴다. 비품 다음 줄의 누계액은 비품 누계액이 된다.
- 분개장의 세부 계정(10301 보통예금)은 계정과목표의 상위 코드, 없으면 백 단위로 올려 시산표 계정에 붙인다.
- 기초는 전기 최종이다. 손익 계정은 0 에서 시작하고, 결손금 · 이익잉여금 계정에는 전기 손익을 더한다(마감 전 시산표 기준).
