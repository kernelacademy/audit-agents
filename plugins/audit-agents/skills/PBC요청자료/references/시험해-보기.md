## 시험해 보기

`examples/모의자료/받은자료/` 는 가상 회사 도담소프트(가상)의 2025 기말감사 1차 수령 자료다. 회사 · 사람 · 거래처 이름과 숫자는 모두 지어냈다.

| 파일 | 내용 |
|---|---|
| `전기/전기 감사보고서_FY2024.pdf` | 전기 감사보고서 19쪽. DART 감사보고서 양식: 표지, 독립된 감사인의 감사보고서(2쪽, 감사인 한울감사반(가상), 적정, 보고서일 2025-03-12), 재무제표 5종(일반기업회계기준), 주석 22개 |
| `전기/전기조서_WTB_2024_v3.1.xlsx` | 전기 감사인 정산표, 시트 10개: 표지(중요성 · 검산) · TB · 재무상태표 · 손익계산서 · AJE(수정분개 3건 · 재분류 1건) · 공시용BS · 공시용PL · 공시용자본변동표 · CF정산표 · 공시용CF. 칸은 수식으로 이어져 있다 |
| `회사제시/1.시산표_회사제시_v1.1.xlsx` · `1.재무제표_회사제시_v1.1.xlsx` | 더존 꼴 합계잔액시산표 · 재무제표 |
| `분개장/2.분개장_회사제시_260131.xlsx` | 2025 분개장 |

```bash
python scripts/run.py new "out/도담소프트(가상)/2025 기말감사" --company "도담소프트(가상)" --fy-end 2025-12-31
# examples/모의자료/받은자료/ 아래 폴더들을 out/도담소프트(가상)/2025 기말감사/00 받은자료/ 에 복사
python scripts/run.py start "out/도담소프트(가상)/2025 기말감사" --no-ocr
python scripts/run.py text "examples/모의자료/받은자료/전기/전기 감사보고서_FY2024.pdf"
python scripts/run.py apply "out/도담소프트(가상)/2025 기말감사" examples/모의자료/판독_patch.json
```

기대 결과: 받은 2 / 18, 빠진 자료 14건(결산일 후 분개장 · 계정명세서 · 세무조정계산서 · 의사록 · 주주명부 · 연령분석표 · 고정자산대장 · 급여대장 · 약정서 · 소송 · 부가세 · 원천세 · 잔액증명 · 개발 프로젝트), 만든 파일 5개. 감사인 이름은 엔진 문형이 못 읽어 판독 필요로 남고, AI 가 2쪽을 읽어 `판독_patch.json` 처럼 넣는다. 2100 기업이해의 「전기 대비 변동」 시트는 과목마다 전기 금액과 증감을 내고, 큰 변동 기준은 전기조서에서 읽은 수행중요성 74,925,000원이다. 「전기 과목 없음」 은 투자유가증권 · 감가상각누계액 두 과목이다.
