# 수령확인

PBC요청자료 스킬의 `next` 를 돌리고, 엔진이 못 보는 것(기간 · 판 · 회사명)만 읽어서 회계사에게 묻는다.

## 순서

PBC요청자료 스킬 폴더(아래 `<PBC>`)는 `${CLAUDE_PLUGIN_ROOT}/skills/PBC요청자료` 다. 그 글이 경로로 바뀌지 않았으면, 이 SKILL.md 가 있는 폴더의 형제 폴더 `PBC요청자료` 를 쓴다(이 플러그인의 `skills/PBC요청자료`). 명령은 cd 하지 않고 절대 경로로 돌리고, 앞에 환경변수를 붙이지 않는다. 회사 폴더 권한 파일이 utf-8 출력을 켜 두었다.

1. **요청 목록 확인**: `_색인/시작자료.json` 이 없으면 PBC요청자료 스킬의 `start` 가 먼저다. 그렇게 말하고 멈춘다. 있으면 `_색인/문서목록.json` 의 `missing`(빠진 자료 목록)과 `files`(받은자료 목록)를 기억한다.
2. **엔진 돌리기**: `python "<PBC>/scripts/run.py" next "<회사 폴더>"`.
3. **바뀐 것 보기**: `_색인/문서목록.json` 을 다시 읽는다. 1단계에서 기억한 `missing` 에 있다가 사라진 항목을 받음으로 바뀐 것으로 본다. 빠진 자료의 정본은 이 `missing` 이다. `next` 는 `시작자료.json` 의 `pbc` 를 다시 쓰지 않으므로 그 상태는 `start` 때 그대로다. `files` 에 새로 생긴 파일이 새로 들어온 파일이다.
4. **새 파일 읽기**: 새 파일마다 기간(회사 `CLAUDE.md` 의 결산일 기준), 회사명, 판(v1.1 · 최종 등)을 확인한다. 엑셀은 엔진 출력과 시트 첫 줄을 보고, PDF 는 `python "<PBC>/scripts/run.py" text "<PDF 절대 경로>"` 로 첫 쪽을 읽는다.
5. **묻기**: 기간이 다르거나 일부만 왔거나 회사명이 다른 파일은 파일마다 선택지 「재요청 · 그대로 받음 · 회계사가 직접 확인」 으로 묻는다. 질문에 파일 이름과 맞지 않는 내용을 그대로 적는다.
6. **남기기**: 고른 답을 `진행메모.md` 의 「정한 것」 에 날짜와 함께 적는다. 재요청이면 「남은 일」 에 「재요청 메일: <항목>」 을 더한다.
7. **보고**: 세 줄. 받음으로 바뀐 수, 아직 빠진 수(`missing` 의 수), 물어본 수.

## 하지 않는 것

- 받은자료 파일을 옮기거나 이름을 바꾸지 않는다.
- 엔진이 판정한 받음 · 빠짐을 손으로 바꾸지 않는다.
- 메일을 보내지 않는다. 초안은 「재요청 메일 초안」 이라고 하면 `_작업/메일` 에 쓴다.
