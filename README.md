## 설치

Claude 앱 Code 탭에서 감사 루트로 쓸 빈 폴더로 세션을 열고 아래처럼 시킵니다. GitHub 로그인은 필요 없습니다.

```
kernelacademy/audit-agents 에서 audit-agents 플러그인을 사용자 범위로 설치해줘
```

승인 질문이 뜨면 허용합니다. 끝나면 세션을 닫고 같은 폴더로 다시 엽니다. 플러그인은 세션을 열 때 불러옵니다.

다시 연 세션에서 `/audit-agents:설치 "<감사 루트 경로>"` 를 실행하면 감사 루트를 만들고 설치 상태를 점검합니다. 이어서 `/audit-agents:새회사 <회사명> <결산일>` 로 회사 폴더를 만듭니다.

Claude Code 를 터미널에서 쓰는 분은 아래 두 줄로도 설치할 수 있습니다.

```
claude plugin marketplace add kernelacademy/audit-agents
claude plugin install audit-agents@kernelacademy-plugins
```

파이썬 3.11 이상이 필요합니다.

## AI감사팀 화면

`/audit-agents:감사팀게시` 는 AI감사팀 화면을 claude.ai 비공개 아티팩트로 올립니다. 고객사마다 인차지 · 연결 폴더 · 세션 상태 · 기다리는 질문 · 토큰을 한 화면에서 봅니다. 고객사와 인차지 설계 카드는 화면의 「설정」에서 넣습니다. 세션은 화면의 「동기화」 문장을 회사 폴더에서 연 Claude Code 세션에 보내야 올라옵니다. 화면에 남긴 답변은 질문한 세션이 다음 동기화 때 읽어 갑니다. 내용은 아티팩트 저장 기능에 남아 다시 게시해도 그대로입니다. 토큰 금액은 API 단가로 환산한 추정값이라 구독 요금제 청구액과 다릅니다. 디자인은 Kernel Academy 「오늘의 AI 비타민」 을 따릅니다.

## 지켜 주실 것

- 에이전트가 만든 조서 · 메일은 초안입니다. 판단과 발송은 회계사가 합니다.
- 고객 자료를 다룰 때는 소속 회계법인의 정보보안 규정을 따르십시오.
- 예제 회사(도담소프트 · 가온정밀)는 가상 회사입니다.
